# Cantoa v18.9.0 — Smart Remix feature release

Cantoa v18.9.0 builds on the v18.8.56 hardened release without replacing its billing, quota, provider-routing, Library or security architecture.

## New
- **Smart Remix Studio**: choose what to preserve from a finished Library song — lyrics, style, voice character, energy and/or structure — then create a linked new version.
- **Match this vibe**: use a Library song as high-level mood/energy/production reference while asking Cantoa for fresh melody/lyrics rather than a copy.
- **Social Cut Creator**: the existing automatic 15-second best-moment workflow is now labelled more clearly.

## Existing creative tools retained
Best of A/B, Change Style, Keep Lyrics / Change Music, Keep Music Feel / New Lyrics, Extend, Replace Section, Instrumental Version, Vocal Version, Blend 2–4 Songs, Song DNA, lyric/square/Reel video, Memory Movie, Group Song and Creator Pack remain available.

## Dark-mode fixes
- Share Song no longer inherits old white panel backgrounds inside dark mode.
- Social destination cards receive explicit dark surfaces and readable text.
- Secret Song Drop now uses the actual light/dark studio theme tokens rather than falling back to white.
- Date/time controls remain visible in dark mode.

## Compatibility
No new SQL or environment variables. Pricing, free limits, Creator/Studio allowances, Stripe setup and provider routing are unchanged.
